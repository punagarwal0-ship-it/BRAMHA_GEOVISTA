# SAR-Accel

Vivado FPGA prototype for SAR image speckle reduction and change detection, with a Python companion app.

## Contents

- `SAR-accel.xpr` and `SAR-accel.srcs/`: Vivado project, RTL, block design, constraints, and testbenches.
- `SAR-Accel-Python-App/`: image pair loader, Python reference, and Vivado input/output helpers.

Generated Vivado run and simulation directories and image memory files are excluded. Recreate simulation pixel files with the Python app.

Open `SAR-accel.xpr` in Vivado. For the Python app, see `SAR-Accel-Python-App/README.md`.
